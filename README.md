# Exposoma Amazônia

Publicação do app Exposoma Amazônia (UFOPA). Este repositório guarda só o app pronto; o código-fonte é privado.

- **Usar no navegador ou instalar no iPhone:** https://joaomarcosgalucio.github.io/exposoma/ (no Safari, Compartilhar › Adicionar à Tela de Início)
- **Instalar no Android:** baixe o [exposoma.apk](https://joaomarcosgalucio.github.io/exposoma.apk) no celular, abra o arquivo e permita "instalar apps desta fonte".
